# Визуальный референс

Сюда кладём референсы (видео, скриншоты, ссылки в `links.md`).

Как используем:
- изучаем **принцип**: ритм склеек, как работает типографика, когда и как появляются мемы,
  freeze frames, punch-in, роль тишины и звука;
- выводы записываем в `editing/ANALYSIS.md` и, если они общие, переносим в `docs/STYLE.md` / `docs/EDITING.md`;
- **не копируем буквально**: композиции, конкретные шрифты, цвета, фирменные элементы чужого автора.

Тяжёлые видеофайлы здесь тоже можно не коммитить — достаточно ссылок и пары кадров.

## Структура

- `editing/` — **главный ориентир**: три видео-референса (ref-a/b/c.mp4), разбор в
  `editing/ANALYSIS.md`, правила монтажа в `docs/EDITING.md`, стиль v2 — `docs/STYLE.md`
- `_archive/` — больше не ориентир: оранжевая карусель (`carousel-2025-09/`, `carousel-NOTES.md`)
