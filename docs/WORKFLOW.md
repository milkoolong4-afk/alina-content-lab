# Workflow: от материалов до готового рилса

## Что присылать

| Материал | Как лучше |
|---|---|
| Видео | как есть, с телефона. Вертикальные — идеально, горизонтальные тоже ок (обрежем/впишем). |
| Screen recordings | телефон или ноутбук, без обрезки — нужные куски выберем сами. |
| Скриншоты | PNG/JPG. Можно помечать, что важно: «смотри на кнопку справа». |
| Мемы | картинка / gif / короткое видео. |
| Войсовер | m4a/mp3/wav. Тихая комната, телефон близко ко рту. |
| Сценарий | текст или просто список битов: «хук — …, потом …, панчлайн — …». |

Достаточно и части: только видео + идея, или только войсовер + скриншоты.

## Что происходит дальше

1. `npm run new -- <slug> "Название"` — создаётся спека из шаблона и папки:
   ```
   public/reels/<slug>/video     — реальные видео, работа, лицо
   public/reels/<slug>/screens   — screen recordings и скриншоты
   public/reels/<slug>/photos    — фото
   public/reels/<slug>/memes     — мемы
   public/reels/<slug>/audio     — войсовер, свои звуки
   ```
2. `npm run probe -- <slug>` — длительности и ориентация всех файлов.
3. Битшит: хук → контекст → эскалация → поворот → финал (см. `src/reels/_template/reel.ts`).
4. Сборка сцен в `src/reels/<slug>/reel.ts`, субтитры по войсоверу.
5. Проверка кадров (stills) → драфт `npm run render -- <slug> --draft` → финал `npm run render -- <slug>`.
6. Готовый файл: `out/<slug>.mp4` (1080×1920, H.264, AAC).

## Работа руками

```bash
npm install
npm run dev          # Remotion Studio: Reels/… и Lab/style-demo, Lab/template
```

В Studio видно все сцены на таймлайне с подписями (`note`). Правишь `reel.ts` — превью
обновляется сразу.

## Тяжёлые файлы

`.mp4/.mov/.wav/.m4a/.mp3` внутри `public/reels/` игнорируются git'ом (чтобы репозиторий
не раздувался). Исходники храни в облаке/на диске; в git остаётся спека.
Если хочешь версионировать и ассеты — убери соответствующие строки из `.gitignore`.

## Форматы

- Если `.MOV` (HEVC с iPhone) не проигрывается в превью:
  `ffmpeg -i in.MOV -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac out.mp4`
- GIF работает напрямую. Длинные GIF лучше перевести в mp4.
