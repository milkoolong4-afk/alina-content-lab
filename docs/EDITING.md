# EDITING STYLE GUIDE — Alina Content Lab

> **Важно (стиль v2 в поиске):** правила монтажа ниже (ритм, лицо, мемы, переходы, звук)
> действуют. Конкретные цвета и шрифты в этом файле (оранжевый, бумага/ink, «жирный гротеск»)
> относятся к архивному стилю v1 — до утверждения v2 читать их как «акцентный цвет / фон /
> основная гарнитура», см. `docs/STYLE.md`.

Постоянное правило проекта. Основано на разборе референсов монтажа
(`reference/editing/ANALYSIS.md`) и на характере блога (`docs/STYLE.md`, `docs/SOUND.md`).
Из референсов взяты только **принципы**: ритм, типографика, работа с лицом, мемами и звуком.
Кадры, тексты, персонажи, дизайн и содержание референсов не копируются.

Формула блога: **дневник, который монтирует дизайнер с мемным чувством юмора.**
Спокойная editorial-основа + резкие мемные удары.

## 0. Главный принцип: стиль единый — формат свободный

**Стиль монтажа един для всех роликов** (ритм, типографика, мемы, звук, переходы — разделы 1–8).
**Формат повествования меняется от ролика к ролику** и выбирается под историю:

| Формат | Чем рассказываем | Текст на экране |
|---|---|---|
| Войсовер | закадровый голос + b-roll, скрины, мемы | субтитры по слову (`captions.mode: "words"`) или строками |
| Talking head | синхрон в камеру, в «окне» и на весь кадр | короткие подписи/панчлайны, субтитры по желанию |
| Текст без голоса | крупная типографика + визуальный сторителлинг | карточки ≤ 6 слов |
| Мемы / скриншоты / вставки | реакции, доказательства, визуальные шутки | минимум, текст внутри мема/скрина |
| Комбинация | любые из выше в одном ролике | по участку |

Войсовер с субтитрами по слову — основной язык проанализированных референсов,
но **не обязательный формат** блога. Ни один формат не является дефолтом: выбор — часть
работы над историей (приоритет №1).

## 1. Ритм

| Правило | Значение |
|---|---|
| Визуальное событие (склейка, слово, стикер, зум, смена фона) | **не реже раза в 1 с** |
| Средняя длина плана | **1.2–2.5 с** |
| Самый короткий план | 0.3 с (укол), не чаще 2 раз подряд |
| Самый длинный план | 4 с, и только если внутри меняется текст |
| Первые 3 секунды | ≥ 3 визуальных события |

- Ролик дышит **волнами**: 3–5 быстрых битов → один «вдох» (однотонная карточка, тишина,
  длинный кадр) → снова быстро.
- Самое быстрое место — хаос/эскалация. Самое медленное — момент честности перед панчлайном.
- Склейка всегда на слове или на ударе, никогда «в середине ничего».

## 2. Лицо (talking head)

- **Я — героиня, а не говорящая голова.** B-roll с собой (работаю, пью кофе, иду, смотрю
  в экран) важнее синхрона в камеру.
- Лицо на весь экран — **≤ 35% хронометража**, кусками по 1.5–4 с.
- Синхрон в камеру — в **рамке**: окно на бумажном/оранжевом фоне, а не всегда full-screen.
  На кульминации окно «вырастает» до полного кадра (punch-in как эмоция).
- Jump cut внутри синхрона: каждые 2–3 с — смена масштаба 1.0 → 1.2–1.35 или смена окна.
- Лицо перебивается графикой/мемом/экраном **минимум раз в 4 с**.
- Freeze на лице — лучший комедийный приём, но **≤ 2 раз за ролик**.

## 3. Типографика

Три регистра, всегда разделены по смыслу:

| Регистр | Шрифт | Для чего |
|---|---|---|
| **Голос** | жирный гротеск | ключевые слова, панчлайны, 1–3 слова |
| _Ремарка_ | курсивный сериф | ирония, «(и я не шучу)», скобки, внутренний голос |
| `Система` | моно | счётчики, «ДЕНЬ 5», ошибки, интерфейс |

- **Если в ролике войсовер и выбран формат «по слову»** — текст идёт за голосом, 1–3 слова
  на экране, предыдущий кусок исчезает. Ключевое слово — в **2–3 раза крупнее** и оранжевое.
  Строками (`mode: "lines"`) — тоже допустимо, если ролик спокойнее.
- **Если войсовера нет** — карточки ≤ 6 слов, ≤ 3 строки.
- Панчлайн — **одно-два слова на весь экран** или финальная фраза на однотонной карточке.
- **Гигантские цифры/слова-главы** («1.», «5 ДНЕЙ», «100») могут наполовину перекрывать
  кадр и человека — это фишка, не ошибка.
- Ироничная ремарка — **после** утверждения, мельче и курсивом: утверждение → ремарка
  сбивает пафос.
- Текст взаимодействует с кадром: стоит вокруг человека, рядом с объектом, на пустом месте
  кадра, а не всегда по центру внизу.
- Строчные для разговорного тона, КАПС — только для ударов.
- Мелкий текст допустим как художественный приём (внутренний голос на чёрном),
  но не для смысла, который нужно прочитать.

## 4. Мемы

- Мем = **реакция**, а не иллюстрация. Ставится **сразу после** реплики, на которую реагирует.
- Длительность **0.6–1.5 с**. Дольше — только если в меме есть текст, который надо прочитать.
- **Мемов ≤ 1 на 5 секунд** в среднем; в блоке хаоса допустимо 3–4 подряд.
- Два формата:
  - **отдельный кадр** (на весь экран или карточкой на однотонном фоне) — для реакции;
  - **стикер поверх видео** (вырезанный объект/лицо) — для комментария без остановки ритма.
- **Сквозной мотив**: один повторяющийся стикер/объект за ролик (как подпись автора).
- Вырезанные предметы-метафоры на однотонном фоне — «тихий мем» для спокойных битов.

## 5. Визуальные перебивки

| Приём | Когда | Лимит |
|---|---|---|
| Punch-in (мгновенный зум 1.2–1.5) | реакция, ключевое слово, деталь экрана | свободно |
| Плавный зум | только на «вдохе», 2–4 с | 1–2 за ролик |
| Freeze frame + подпись | «она ещё не знает…», «в этот момент я решила…» | ≤ 2 |
| Ч/б | сомнение, провал, «до» | 1–2 блока |
| Чёрный экран + мелкий текст | внутренний голос, пауза перед панчлайном | ≤ 1 |
| Однотонная карточка (оранжевый/бумага/ink) | глава, слово-удар, вдох | свободно |
| Скриншоты/записи экрана | доказательство: «это правда было» | свободно |
| Всплывающие скрины/уведомления пачкой | реакция мира, хаос | 3–4 за 1.5 с |
| Рисованные стрелки/обводки | указать на деталь экрана | свободно |

## 6. Переходы

**Используем:** жёсткая склейка (по умолчанию, ≥ 90% стыков), смена фона под тем же
объектом, вспышка на 2–4 кадра, glitch на 4–6 кадров, «окно растёт до полного кадра».

**Один «эффектный» переход за ролик** — перед кульминацией или панчлайном.

**Не используем:** растворения/fade, вращения, 3D, шторки, «зум-трансформации» из шаблонов,
светящиеся переходы, морфинг.

## 7. Звук

- **Войсовер — хребет.** Всё остальное ниже на 12–18 дБ.
- **Музыка:** по правилу блога — **по умолчанию нет**. Референсы используют тихую
  подложку; у нас её заменяют:
  - тишина и комнатный звук самих видео;
  - **низкий гул/бум** под драматический момент (сомнение, провал) — 1 раз за ролик;
  - если подложка всё-таки нужна — громкость ≤ 0.08, без мелодии, обрывается в паузах.
- **SFX — только на смысловых событиях:** всплыли сообщения → пинг; ошибка → error;
  панчлайн → impact; freeze → shutter/scratch; мем → короткий комедийный звук.
  Ориентир **5–9 SFX на 30–35 с**.
- **Audio cut перед последним словом/панчлайном** (0.3–0.6 с полной тишины) — обязателен.
- Громкость готового ролика: **−14 LUFS** (как у всех трёх референсов), пик ≤ −1 dBFS.

## 8. Ощущение

Личный, честный, немного дерзкий, смешной. Зритель должен чувствовать:
«она реально это делает и смеётся над собой», а не «мне продают приложение».

## Чек-лист перед рендером

1. Первые 3 с: ≥ 3 визуальных события, фраза-хук читается за 1.5 с.
2. Нет плана длиннее 4 с без смены текста/масштаба.
3. Лицо на весь экран ≤ 35%; лицо перебито минимум раз в 4 с.
4. Формат повествования выбран под историю. Каждая надпись: ≤ 6 слов (карточки) / 1–3 слова (субтитры по слову), внутри безопасных зон.
5. Есть хотя бы одна ироничная ремарка курсивом.
6. Мемы — реакции 0.6–1.5 с, не чаще 1 на 5 с вне хаоса.
7. ≥ 90% стыков — жёсткие склейки; ≤ 1 эффектный переход.
8. SFX 5–9 штук; перед панчлайном тишина; нет постоянной музыки.
9. Громкость −14 LUFS ±1, пик ≤ −1 dBFS.
10. Финал — шутка, не CTA.
