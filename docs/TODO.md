      + текст, который читала. Решение: пишем голос сами, без AI-озвучки (Voicebox рассмотрен и отложен).

      `audio/vo.words.json` → `linesFromWords()` → субтитры «по слову».
      whisper.cpp собран. **Блокер:** модель скачивается с `huggingface.co`, этот хост закрыт
      в сетевых настройках облачного окружения — Алине разрешить его (Custom → Allowed domains).
      После этого — тест на русской речи и первый войсовер.
      Для day-25 тайминги сделаны офлайн-моделью GigaAM (sherpa-onnx, модель с GitHub —
      он открыт) во временной папке: результат точный. Если huggingface останется закрыт —
      перевести `npm run timings` на этот движок.

      (ноутбук, кружка, телефон, кот, если он в истории). iPhone: «Фото» → долгое нажатие на объект →
      «Скопировать»/«Поделиться» → PNG. Складываем в `public/stickers/`.
- [ ] **4. Настоящие звуковые эффекты** вместо синтезированных заглушек: scratch, impact, pop,
