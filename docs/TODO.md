# План подготовки — идём по шагам

Из технического аудита после разбора референсов монтажа (`docs/EDITING.md`).
Отмечаем `[x]` по мере выполнения. Порядок важен: каждый шаг опирается на предыдущий.

## A. Необходимо

- [ ] **1. Войсовер** — записать и передать первый файл голоса
      (M4A с диктофона / WAV / MP3, один дубль, без музыки). ← **текущий шаг**
- [ ] **2. Пословные тайминги для субтитров** — поставить локальный Whisper
      (`@remotion/install-whisper-cpp`), прогнать первый войсовер, сделать субтитры
      «по слову» с увеличенным ключевым словом. Делаем, когда есть шаг 1.
- [ ] **3. Вырезанные PNG с прозрачным фоном** — Алина в нескольких позах + 3–5 предметов-метафор
      (ноутбук, кружка, телефон, кот, если он в истории). iPhone: «Фото» → долгое нажатие на объект →
      «Скопировать»/«Поделиться» → PNG. Складываем в `public/stickers/`.
- [ ] **4. Настоящие звуковые эффекты** вместо синтезированных заглушек: scratch, impact, pop,
      whoosh, click, error, notification, keyboard + новый `drone` (низкий гул/бум).
      WAV/MP3, отдельными короткими файлами, кладём в `public/sfx/` с теми же именами.

## B. Полезно, но не обязательно

- [ ] **5. Сквозной стикер-мотив** — один узнаваемый объект/стикер, который повторяется из ролика в ролик.
- [ ] **6. Библиотека звуков** (Pixabay / Freesound) — источник файлов для шага 4, без интеграции.
- [ ] **7. Текст «за» человеком** (как в ref-c) — нужна покадровая маска фигуры; тяжело, откладываем.

## Доработки движка (после подтверждения, библиотек не требуют)

- [ ] Субтитры по слову (кинетические, ключевое слово крупнее) — вместе с шагом 2
- [ ] Лицо «в окне» на фоне + рост окна до полного кадра
- [ ] Ч/б режим для любой сцены

- [ ] `drone` в библиотеке звуков — вместе с шагом 4
