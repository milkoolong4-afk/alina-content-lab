# Стиль Alina Content Lab

Личный интернет-блог, а не реклама приложения. Аккуратная editorial-типографика
сталкивается с мемным хаосом — в этом контрасте и есть характер.

> Это отдельная визуальная система. Ничего не берём из Kedice (цвета, шрифты,
> персонажи, компоненты, звук). Kedice может быть в кадре только как продукт
> в истории — её экраны показываем как есть.

## Палитра

| Токен | Цвет | Для чего |
|---|---|---|
| `orange` | `#FF5A1F` | главный акцент, фоны карточек, стикеры, выделения |
| `ink` | `#0D1230` | текст, плашки, рамки — тёмно-синий почти чёрный |
| `paper` | `#F4F0E8` | тёплый светлый фон карточек |
| `alert` | `#FF2E3A` | только ошибки и штамп FAIL |
| `marker` | `#FFE45C` | только маркер-выделение на скриншотах |
| `ok` | `#1FCB6B` | редкий момент «оно работает» |

Три основных цвета: orange / ink / paper. Остальное — по смыслу и редко.

## Шрифты

- **Display** (Inter Tight 900) — основной голос. Крупно, плотно, трекинг −3.5%.
- **Serif** (Playfair Display italic) — `_ироничная ремарка_`, editorial-контраст.
- **Hand** (Caveat) — «вот тут я плакала», стрелки, подписи от руки.
- **Mono** (JetBrains Mono) — терминал, ошибки, счётчики «ДЕНЬ 47», кикеры.

Все шрифты лежат локально в `public/fonts` (лицензия OFL), рендер не зависит от интернета.

## Разметка текста

`*слово*` → оранжевое · `[слово]` → плашка · `~слово~` → зачёркнуто · `_слово_` → серифный курсив

Пример: `"я ~программист~ _человек с ноутбуком_"`

## Типографика

- Коротко: ≤ 6 слов на карточку. Если длиннее — разбей на две карточки.
- Один акцент на фразу. Два оранжевых слова — уже шум.
- Выравнивание по левому краю по умолчанию (editorial); центр — для одиночного удара.
- Размер подстраивается сам, чтобы самое длинное слово влезало в кадр.

## Монтаж

- **Хук за 1.5 с**: сильнейший кадр + короткая фраза. Без приветствий и логотипов.
- **Ритм**: средний план 0.8–2.5 с, но меняй его: укол 0.4 с рядом с удержанием 3 с.
- **Жёсткие склейки** по умолчанию. Переходы (`flash`, `glitch`, `whip`, `zoom`, `drop`) — специи, не больше одного на 4 сцены.
- **Punch-in** (`zooms` с `duration: 0`) — на реакцию, на ключевое слово, на деталь экрана.
- **Freeze frame** — главный комедийный инструмент: «она ещё не знает…». Стили: `flash`, `orange` (дуотон), `mono`, `plain`.
- **Резкая смена визуала** — нормально. Из спокойного экрана → в оранжевую карточку → в мем.
- **Тишина** (`beat` + `audioCuts`) — пауза перед панчлайном работает сильнее любого звука.
- Лицо — дозированно: реакция, взгляд в камеру, короткий комментарий. Не более ~30% хронометража.

## Чего избегать

- плавных fade/dissolve, «кинематографичных» переходов, параллакса ради параллакса;
- градиентов, неонового свечения, мягких теней (только жёсткая тень `hardShadow`);
- стоковой эстетики, «вдохновляющих» формулировок, CTA «подписывайтесь!» в конце;
- шаблонных TikTok-эффектов (эмодзи-дождь, глянцевые титры);
- мотивационной/корпоративной/lo-fi музыки.

## Безопасные зоны

Верх 220 px, низ 400 px, справа 150 px — там интерфейс платформ. Важный текст — внутри.
Проверка: `look: { guides: true }` в спеке (перед финальным рендером выключить).
