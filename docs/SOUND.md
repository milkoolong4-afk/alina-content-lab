# Sound design

Звук — отдельная часть стиля. Он усиливает шутку или склейку. Он не «заполняет».

## Основа

- **Никакой постоянной фоновой музыки по умолчанию.** Поле `music` есть, но громкость
  по умолчанию 0.12, и это последний приоритет.
- Нельзя: motivational, corporate, lo-fi, спокойный «технологичный» фон, милая музыка,
  музыка как у рекламы образовательных приложений.
- Звук оригинальных видео выключен по умолчанию (`volume: 0`). Включай, только если
  реальный звук — часть шутки (стон, «ой», клавиатура в 3 ночи).

## Библиотека (`src/sfx/library.ts`)

| Имя | Когда |
|---|---|
| `click` | тап / клик по UI, курсор |
| `keyboard` | пара нажатий |
| `typing` | активный набор (обрезай `duration`) |
| `notification` | пуш, сообщение |
| `error` | системная ошибка, build failed |
| `pop` | появление стикера / лейбла |
| `whoosh` | `whip`-переход |
| `impact` | тяжёлый удар: реверс, штамп, панчлайн |
| `thud` | мягкий удар: slam-текст |
| `drone` | низкий бум → гул (~3 с): сомнение, провал, «ой нет». Один раз за ролик |
| `scratch` | record scratch — «стоп, что?» (часто + freeze) |
| `shutter` | freeze frame, скриншот |
| `bonk` | комедийный удар по голове |
| `boing` | мультяшная пружина |
| `glitch` | цифровой сбой, `glitch`-переход |
| `ding` | «оно работает» (редко!) |
| `tick` | счётчики, пункты списка |

Файлы в репозитории — **синтезированные заглушки** (`npm run sfx`), чтобы всё рендерилось
сразу. Для финальных роликов положи настоящие записи с теми же именами в `public/sfx/`
(например из своей библиотеки звуков) — спеки менять не нужно. Можно добавить новые имена
в `SFX`, либо указать путь прямо в cue: `{ at: 1, sfx: "reels/my-reel/audio/oops.wav" }`.

## Правила

1. Не на каждую склейку. Ориентир: 4–8 звуков на 30 секунд.
2. Тишина — часть шутки: `beat`-сцена и `audioCuts` (глушат музыку и звук видео; SFX — нет).
3. Звук чуть раньше картинки (1–2 кадра) воспринимается «точнее».
4. Войсовер всегда главный: SFX под голосом — тише (0.3–0.5).
5. Один «громкий» звук (impact/scratch) на ключевой момент. Если всё громкое — ничего не громкое.

## Пример

```ts
audioCuts: [{ from: 18.2, to: 19.4 }],          // обрыв всего, кроме SFX
sfx: [{ at: 18.2, sfx: "scratch", volume: 0.9 }], // абсолютное время
scenes: [{ ..., sfx: [{ at: 0.3, sfx: "pop", volume: 0.5 }] }], // время внутри сцены
```
