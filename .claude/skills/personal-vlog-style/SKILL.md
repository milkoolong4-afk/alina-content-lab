# Личный vlog-стиль Алины

Это стиль для роликов "я — основательница приложения", отдельно от обучающего контента Kedice с котами. Основа — настоящие кадры с Алиной, а не иллюстрации.

Визуальный язык ниже (шрифты, вырезки, коллаж, палитра) — это направление и набор доступных приёмов, а не утверждённый финальный вид. Если стиль v2 проекта ещё не утверждён — предлагай пробы/варианты на этой основе, а не навязывай готовый облик одним вариантом.

## Структура ассетов (постоянная библиотека)

Этот скилл работает вместе с папками в репозитории — сам скилл не хранит файлы, а объясняет, как их использовать. Имена файлов внутри папок случайные — выбирай по содержимому (просмотри/прослушай), а не по названию.

Проект собран на Remotion — все рабочие медиафайлы лежат в `public/` (так Remotion их видит при рендере). Папка `reference/` в репозитории — это архив визуальных референсов для вдохновения, не рабочие ассеты.

- `public/backgrounds/` — фоновые текстуры/паттерны
- `public/stickers/` — PNG-стикеры/вырезки на белом или прозрачном фоне
- `public/stickers/mine/` — приоритетные, собственные стикеры Алины (использовать в первую очередь, если подходят по теме)
- `public/fonts/` — файлы шрифтов (жирный sans + рукописный акцент)
- `public/animations/` — gif-анимации для акцентов/переходов
- `public/sfx/` — короткие звуки, одной папкой без подпапок: `click.wav`, `pop.wav`, `whoosh.wav` + треки Epidemic Sound
- `public/palettes/` — цветовые схемы/сочетания (сейчас это набор файлов `IMG_3826-3841.JPG`, без выделенного дефолта). Палитру для конкретного ролика всегда указывает Алина в брифе — файла "по умолчанию" нет, без явного указания не выбирай сама, спроси.

Если какой-то тип файла нужен, но его нет в соответствующей папке — не выдумывай замену молча, спроси Алину, что добавить.

## Исходники для конкретного ролика

Каждый ролик собирается из 5-6 новых сырых клипов/фото, которые Алина присылает под конкретный сценарий, плюс бриф с хуком и раскадровкой. Без свежих клипов и брифа ролик не собрать — это каждый раз новое, в отличие от ассетов выше.

## Текст на экране

- Основной текст — крупный, жирный sans-serif, часто строчными буквами. В `public/fonts/` уже есть Inter Tight (веса 600-900) — использовать его как основной жирный текст.
- Акцентные слова/цифры — рукописный курсивный шрифт, крупно, часто одно слово. В `public/fonts/` уже есть Caveat — использовать для акцентов.
- Для заголовков с более editorial-настроением доступен Playfair Display, JetBrains Mono — для технических/кодовых акцентов (например, при показе кода).
- Не смешивать больше двух шрифтов на одном видео.

## Фейковые UI-элементы (опционально, для вовлечения)

- Скроллящиеся уведомления "X started following you" полупрозрачным слоем за кадром
- Карточка "tap to watch" с иконкой глаза и счётчиком просмотров поверх превью
- Скриншоты монтажной программы/рабочего экрана как один из элементов коллажа

## Эффект "бумажная вырезка"

Либо используется готовый стикер из `public/stickers/`, либо новое фото Алины обрезается по силуэту (убрать фон) и получает белую обводку 8-12px, как у стикера. Размещается на сплошном пастельном фоне (голубой, кремовый, розовый).

## Коллажная композиция

Несколько фото/видео разного размера расположены внахлёст на текстурном или пастельном фоне (точки, лёгкий узор). Один кадр обычно крупнее и в центре — это "главное" видео, остальные — по краям как контекст.

## Движение и тайминг

Правила монтажа (темп, склейки, частота звука) задаёт `CLAUDE.md` / `docs/EDITING.md` проекта — этот скилл их не переопределяет, а дополняет визуальным языком:

- **Склейки** — жёсткие по умолчанию, мягкий переход (свайп/зум) не чаще одного раза на 4 сцены (как в проектных правилах)
- **Звук** — не на каждое появление элемента. SFX ставится только под акцент: шутку, смысловую склейку, сильный визуальный момент. Тишина — тоже приём, не заполнять её звуком через силу
- **Появление текста** — slide-up снизу или fade-in, короткая длительность (0.2-0.3 сек)
- **Появление стикера/вырезки** — bounce-in или scale-up с лёгким overshoot, когда это и есть тот самый акцентный момент
- **Рукописная пометка (кружок/стрелка)** — рисуется "от руки" за 0.3-0.5 сек, используется точечно, не на каждом кадре

Если здесь что-то расходится с `CLAUDE.md` — побеждает `CLAUDE.md`, этот раздел скилла только про стилистику самого движения, не про частоту.

## Рукописные пометки

Поверх кадра — кружки, подчёркивания, стрелки от руки (можно сгенерировать как SVG-штрихи поверх видео), обычно одним акцентным цветом.

## Цвет

Берётся из `public/palettes/` — конкретную палитру указывает Алина в брифе под каждый ролик (разные ролики могут быть в разных цветах). Общее правило: не более 3 цветов на кадр, один из них — акцентный для текста/обводок.

## Звук

**Фоновая музыка/трендовый звук** — не нужен от Claude Code, Алина сама подбирает и накладывает его при публикации в Instagram.

**Короткие SFX-эффекты** (важно для стиля) — на каждом переходе и появлении элемента должен звучать короткий звук из `public/sfx/`, это и даёт ощущение "живости" у референсов:

- **Щелчок (click)** — когда появляется текст или фейковый UI-элемент (уведомление, карточка "tap to watch")
- **Свайп/лист (page-flip, swoosh)** — при смене кадра в коллаже или сдвиге фото
- **Поп (pop)** — при появлении рукописной пометки/кружка

## Чего избегать

- Больше 2 шрифтов и больше 3 цветов на одном кадре
- Статичного, "плоского" текста без лёгкой анимации появления (fade/slide), если инструмент это позволяет
